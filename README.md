# LlmLang

**A programming language whose runtime is an LLM + tools.**

Not a prompt wrapper. A real language: syntax, AST, interpreter, confidence-based control flow, parallel model calls, and a tool system for coding, websites, data, and APIs.

```bash
python -m llm_lang --demo
python -m llm_lang --eval
python -m llm_lang --live
python -m llm_lang --agent
python -m llm_lang path/to/file.ll
```
